# 电商图工作室 · 影策插件

通过商品参考图生成白底主图、使用场景图、核心卖点图、材质细节图、SKU规格图及活动横幅图。使用影策原生生图参数面板，无额外网页或独立服务。

## 安装和配置

1. 影策管理员进入 `/admin/plugins`，上传 `ecommerce-image-studio-1.0.0.yingce-plugin` 并启用。
2. 在系统渠道或自定义渠道中选择「电商图工作室 · 商品参考图生成」协议，配置自己的 API Key 和 Base URL。默认地址是 `https://api.openai.com`；兼容服务必须支持 JSON 形式的 `POST /v1/images/edits`（`images: [{image_url: ...}]`），仅支持 multipart 的服务不兼容本版。
3. 添加该服务实际支持的图片编辑模型 ID，启用 image 能力及插件参数。不要将插件 ID 当作模型 ID。模型和服务必须支持参考图、PNG输出及所选尺寸/质量。
4. 在画布上传商品图，并将图片节点连接到生图节点作为参考；或在创作页添加参考图。选择上一步模型。
5. 填入商品名称、真实卖点和画面需求，在参数中选择图片用途、风格、文案处理、尺寸和候选数量，然后生成。

本包只声明协议；不会附带密钥、购买额度或自动绑定你已有的其他模型渠道。真实生成按所配服务计费。普通用户安装权限以宿主版本与管理员设置为准。

## 使用方式

- 至少1张、最多6张参考图；第一张为商品身份依据。应选择清晰、无遮挡的商品图。
- 图片用途：6种；风格：简洁棚拍、温暖生活、冷调科技、深色质感。
- 文案：默认不生成文字；可仅留文案区，或使用用户指定的文案。商品包装原有文字仍要求保留。
- 白底主图默认不加文案。需要图上文案时请选择卖点图或横幅图。
- 默认尺寸1024×1024；竖图1024×1536、横图1536×1024。横幅图需手动选择横向尺寸。
- 同款候选数量1–4，仅生成当前图型的候选，不代表一次生成整套6种图。
- 制作系列：重复使用同一组商品参考图、风格和品牌视觉约束，逐次切换图片用途。该约束有助于一致性，但不能保证像素级复刻。
- SKU模式仅整理真实提供的款式；不要用单张商品图推测其他款式。细节模式只展示参考图中可见的结构。

商品事实写在提示词框；风格/图型由插件自动追加，不必粘贴长提示词。示例见 `docs/example-brief.txt`。

## 输出与限制

图片由影策现有任务和素材流程接收；支持上游返回图片URL或PNG Base64。插件不修改原始商品图。
它不含抠图算法、图文后期排版、自动整套批量队列或详情页长图拼接。AI可能改变包装细字、局部形状或纹理，上架前应检查商品外观、文案、尺寸和平台要求；插件不声称自动满足所有电商平台规范。

## 开发

源码 `build.py` 从 `source/openai-images.manifest.json` 构建，Python标准库即可：`python build.py`。安装包是ZIP，清单位于根目录；所有模板在 `build.py` 中，修改后重新构建。
协议基于 https://github.com/ddcat-ai/open-ai-canvas 的官方 OpenAI Images 插件，保留其MIT许可证；兼容性和验证记录见 `docs/COMPATIBILITY.md`。
