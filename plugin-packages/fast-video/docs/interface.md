# Fast Video 接口字段

## 协议身份

- 插件 ID：`fast-video`。
- Provider ID：`fast-video`。
- 能力：`video`。
- 默认 Base URL：`https://43.161.242.42/v1`。
- 鉴权驱动：`bearer`。
- 创建：`POST /v1/videos`。
- 查询：`GET /v1/videos/{{taskId}}`。
- 结果：`GET /v1/videos/{{taskId}}/content`。

## 配置字段

| 字段 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `apiKey` | secret | 是 | API Key |

## 统一字段映射

| 统一字段 | 类型 | 必填 | 上游映射 | 说明 |
| --- | --- | --- | --- | --- |
| `model` | string | 是 | `model` | 视频模型 ID（fast 或 mini）。 |
| `prompt` | string | 是 | `prompt` | 视频生成提示词（1-5000 字）。 |
| `duration` | integer | 否 | `seconds` | 视频时长（4-15 秒）。 |
| `aspectRatio` | string | 否 | `ratio` | 视频比例（如 16:9）。 |
| `resolution` | string | 否 | `resolution` | 视频分辨率（如 720p、480p）。 |
| `generateAudio` | boolean | 否 | `withAudio` | 是否生成音频（布尔值）。 |
